# 🌸 Flower Gallery

A beautiful and responsive **Flower Gallery** application built using **React** and **Tailwind CSS**.  
This app showcases a collection of flower images in an elegant and mobile-friendly grid layout.

## ✨ Features

- Responsive gallery layout  
- Smooth hover effects on images  
- Image modal or preview (optional if you implemented it)  
- Clean and modern UI with Tailwind CSS  
- Easy to customize and extend

## 🚀 Technologies Used

- React  
- Tailwind CSS

## 📦 Installation

1. **Clone the repository**

```bash
git remote add origin https://github.com/Harsh-P30/Flower-Gallery.git
```
```bash
cd flower-gallery
```
Install dependencies

```bash
npm install
```
Start the development server

```bash
npm start
```
The app will run at http://localhost:5174.

🛠️ Folder Structure

```bash
/src
  ├── components/
  │    └── Gallery.js
  ├── assets/
  │    └── images/
  ├── App.js
  └── index.js
```
